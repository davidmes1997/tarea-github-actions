# Rebase interactivo

## Objetivo
Limpiar el historial de commits.

## Pasos realizados

1. Se ejecutó:
   git rebase -i HEAD~3

2. Se usó:
   - reword: para mejorar mensaje
   - squash: para unir commits

3. Resultado:
   - Un historial más limpio
   - Mensajes claros y descriptivos

## Decisiones
Se fusionaron commits pequeños porque no aportaban valor individual.
